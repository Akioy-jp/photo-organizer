【症例写真自動整理システム 起動方法】
======================================

【毎日の使い方】

1. PhotoOrganizer.exe をダブルクリックする

2. 黒い画面に以下が表示されれば起動成功です
   ----------------------------------------
   Photo Auto-Organization System Running
   Watching: （監視フォルダのパス）
   Press Ctrl+C to stop
   ----------------------------------------

3. 診療中はこの黒い画面を閉じないでください
   （閉じると自動整理が停止します）


【症例写真の撮影手順】

1. 患者さんの写真をすべて撮影する

2. qr-generator.html をダブルクリックして開く

3. 患者番号を入力して「QRコード生成」をクリック

4. 「全画面表示」でQRコードを大きく表示する

5. カメラでQRコードを撮影する（最後の1枚）

6. 自動で患者番号フォルダへ整理されます


【監視フォルダの変更方法】

config.json をメモ帳で開いて
"watch_folder" の行のパスを変更してください


【困ったときは】

_error フォルダ内のファイルをご確認ください
photo_processor.log にも記録されています
